Comment jouer — Version 3.0

Sauve Saturne : glisse la planète dans le cercle doré sans toucher le chat. Tu peux aussi utiliser les flèches et « Sécuriser ». Trois trajets sûrs terminent l’aventure.

Pizza comète : appuie sur « Livrer » quand la pizza est dans la zone dorée. Trois livraisons terminent l’aventure. Le mode calme permet le positionnement manuel ; VoiceOver et la réduction des animations l’activent automatiquement.

Constellation : mémorise la suite numérotée. Quand les chiffres disparaissent, touche les étoiles dans cet ordre. « Montrer l’ordre » permet de la revoir. Termine trois suites.

Chaque aventure terminée offre un souvenir fixe, sans doublon. Les aventures réussies sont enregistrées ; les manches inachevées recommencent après avoir quitté le jeu. Les trois jeux peuvent être rejoués à tout moment.

Tout le contenu de la chambre reste disponible : 18 souvenirs animés, voyage quotidien dans la boule, musique et objets trouvés cosmiques. Trois souvenirs différents gagnés dans les jeux ou voyages quotidiens ouvrent la pièce bonus. Les souvenirs obtenus peuvent être animés à nouveau.

Les pensées, questions, favoris et le partage sont dans la section secondaire « Pensées et fantaisie ». Ce sont des textes de divertissement, pas de vraies prédictions.

Choisis la langue dans le menu d’accueil. Utilise l’oracle du jour ou saisis une question ; les réponses sont un divertissement fictif. Entre dans la chambre des étoiles et touche la grande boule pour le voyage quotidien. Les voyages terminés restent verrouillés jusqu’au prochain jour local ; les voyages interrompus peuvent reprendre. L’oracle habituel reste ouvert. Active la musique avec le haut-parleur ; vérifie le volume et le mode silencieux. Elle s’arrête en quittant la pièce ou en arrière-plan. Les souvenirs sont dans la pièce et les favoris derrière le signet. Balaye pour supprimer un favori, ou utilise À propos et confidentialité pour effacer les données locales ; le verrou quotidien reste actif. Aucun compte ni restauration par serveur. Pour de l’aide, envoie version app/iOS, appareil et description du souci à mtierlusch@web.de, sans questions ni favoris sensibles.
