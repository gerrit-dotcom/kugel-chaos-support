Choisis la langue dans le menu d’accueil. Utilise l’oracle du jour ou saisis une question ; les réponses sont un divertissement fictif. Entre dans la chambre des étoiles et touche la grande boule pour le voyage quotidien. Les voyages terminés restent verrouillés jusqu’au prochain jour local ; les voyages interrompus peuvent reprendre. L’oracle habituel reste ouvert. Active la musique avec le haut-parleur ; vérifie le volume et le mode silencieux. Elle s’arrête en quittant la pièce ou en arrière-plan. Les souvenirs sont dans la pièce et les favoris derrière le signet. Balaye pour supprimer un favori, ou utilise À propos et confidentialité pour effacer les données locales ; le verrou quotidien reste actif. Aucun compte ni restauration par serveur. Pour de l’aide, envoie version app/iOS, appareil et description du souci à mtierlusch@web.de, sans questions ni favoris sensibles.
